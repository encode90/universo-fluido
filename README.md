# Universo Fluido

A self-contained Spanish learning experience about spacetime, quantum vacuum, superfluids, analogue gravity, emergent gravity, and dark matter.

## Open the site

[Read the interactive learning edition](https://encode90.github.io/universo-fluido/).

The page includes nine lessons, 21 worked equation entries, 78 contextual glossary entries, and 16 original visual laboratories. It distinguishes experimental evidence, conditional mathematical results, hypotheses, and teaching analogies.

## Run locally

Download `index.html` and open it in a modern browser. Content and interactions are bundled in the file; external references are optional. Notes and self-assessment progress stay in the browser and are not uploaded.

## Publication

GitHub Pages serves the root of the `main` branch. `.nojekyll` keeps the site as plain static HTML.

## Scope

This is educational material, not a confirmed theory that the universe is literally a fluid. The source video was not independently transcribed or audited in full. See the in-page explanations and references for assumptions and limitations.
